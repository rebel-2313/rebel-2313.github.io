# 杨叶珥 · 个人主页（求职向静态网站）

一个**纯手写静态网站**：只用 HTML / CSS / JavaScript，不依赖任何框架、构建工具和第三方 CDN，用来在毕业求职时展示个人信息、教育背景、项目经历、课程与证书，并部署在云服务器上供公网访问。

> 本项目由课程作业要求驱动：**文档全部用 Markdown 撰写**、**用 Git 做版本管理并保留关键提交记录**、**部署到云服务器可公网访问**、**允许使用 AI 辅助开发**。

---

## 一、这个网站现在是什么样

- **风格**：专业简洁（深蓝 + 单一强调色），信息密度优先，方便 HR 在 30 秒内抓到重点
- **板块**：首屏 → 关于我 → 教育背景 → 专业技能 → 项目经历 → 主修课程 → 证书荣誉 → 成长轨迹 → 校园生活 → 最近在学 → 联系方式
- **能力**：亮色/暗色主题切换、手机自适应、鼠标微光装饰、相册点击放大、打印即导出简历（Ctrl+P）
- **零依赖**：断网、离线、任何静态服务器都能直接用

## 二、三分钟跑起来

| 想做什么 | 怎么做 |
| --- | --- |
| 本地看效果 | 双击 `index.html`（或双击 `启动本地预览.bat` 起一个本地服务器） |
| 改文字内容 | 只改 `assets/js/content.js`，保存后刷新浏览器 |
| 改配色 | 只改 `assets/css/style.css` 顶部的 `--accent` |
| 换成自己的照片 | 图片放进 `assets/img/`，再把 `content.js` 里的 `avatar` 改成新文件名 |
| 发布到公网 | 见 [docs/05-部署上线指南.md](docs/05-部署上线指南.md) |

## 三、目录结构

```
personal-site/
├─ index.html                 页面骨架（只放静态元信息，正文由 JS 渲染）
├─ resume.md                  纯文本 / Markdown 版简历（关掉 JS 也能看）
├─ assets/
│  ├─ css/style.css           全部样式与配色变量
│  ├─ js/content.js           ★ 内容层：所有文字、链接、图片路径都在这里
│  ├─ js/main.js              渲染层：把 content.js 变成页面（一般不用改）
│  └─ img/                    头像、相册等图片
├─ docs/                      全部项目文档（Markdown）
├─ deploy/                    云服务器部署配置与脚本
├─ serve.ps1                  本地预览服务器（Windows PowerShell）
└─ 启动本地预览.bat             双击即可本地预览
```
