# 我的个人网站（大学生日常 · 赛博朋克版）

一个纯静态的个人网站：不用装任何东西、不用编译，双击就能看。风格是霓虹赛博朋克，背景会跟着鼠标动（光晕 + 准星光标 + 网格探照灯 + 扫描线）。内容全部面向"大学生的日常和爱好"，改一个文件就能变你自己的。

## 目录里有什么

| 文件 / 文件夹 | 作用 |
| --- | --- |
| `index.html` | 网页本体，包含跟随鼠标的特效层（一般不用改） |
| `assets/js/content.js` | **你要改的就是这个**：名字、日常、爱好、作品、联系方式 |
| `assets/js/main.js` | 渲染逻辑 + 光标特效（不用改） |
| `assets/css/style.css` | 样式与配色（想换主题色就改开头的三个霓虹色） |
| `assets/img/` | 头像、作品封面、相册图片（现在是占位图，换成你自己的） |
| `启动本地预览.bat` | 双击运行：打开浏览器，并生成一个局域网网址给朋友看 |
| `serve.ps1` | 上面那个 bat 调用的本地服务器脚本 |

## 三种打开方式

1. **自己先看看**：双击 `index.html`（鼠标在页面上移动，就能看到背景光晕跟着走）。
2. **给同一 WiFi 下的朋友看**：双击 `启动本地预览.bat`，把窗口里打印的 `http://192.168.x.x:8080/` 发给他们，关掉窗口就下线。
3. **让互联网上所有人访问**：见下面「上线到公网」。

## 鼠标特效是怎么回事

- **光晕**：一团霓虹光跟着鼠标走，用缓动追上来，停一会儿会自动淡出；按鼠标键会闪一下。
- **准星**：鼠标位置有一个青色圆环 + 粉色小点；移到按钮、链接上会变成粉色。
- **网格探照灯**：背景有一层霓虹网格，只有鼠标附近才看得清，像手电筒照上去。
- **扫描线**：整页一层很淡的横向扫描线，负责营造"屏幕感"。

想调整：

- 觉得光晕太大/太小：`style.css` 里 `.fx-glow` 的 `width` / `height`（现在是 520px）。
- 觉得太亮/太淡：`--glow-opacity`（亮色主题 `.5`、暗色主题 `.95`）。
- 觉得网格太明显：`.fx-grid` 的 `opacity`（现在跟着 `--grid-strength` 走）。
- **完全不想要这个特效**：把 `index.html` 里 `<div class="fx" id="fx">…</div>` 整段删掉即可。
- 手机上不会出现光晕和准星（触屏没有鼠标），只保留一层很淡的网格；系统里开了"减少动态效果"时同理。

## 把它变成你自己的

只改 `assets/js/content.js` 一个文件。它里面每一段都有中文注释，顺序是：

- `meta`：浏览器标签页标题、分享出去时的描述、左上角站名
- `hero`：首屏的名字、身份、自我介绍、头像、按钮、下面那排小数字、跑马灯标签
- `about`：关于我的段落、快速信息（学校/专业/年级/常出没）、关键词、签名
- `life`：**我的一天 / 作息表**（时间 + 在做什么 + 地点标签 + 备注）
- `skills`：技能点分组
- `projects`：在忙的事（课程项目、社团、自己的小项目）
- `timeline`：大学时间线
- `gallery`：校园日常相册（点图片可以放大）
- `now`：**最近在玩 / 在听 / 在追 / 在吃**
- `contact`：邮箱和社交链接（约饭、组队开黑）
- `custom`：**自定义板块**，默认给了一个"食堂红黑榜"的例子，可以直接写 HTML

改的时候注意三件事：

1. 文字写在英文引号里：`title: '你好'`，别用中文引号。
2. 每一项之间用英文逗号 `,` 分隔。
3. 不想要某个板块：把它的 `items` 改成 `[]`，或整段删掉，页面和导航都会自动少一项。

### 换成自己的图片

把图片放进 `assets/img/`，再把 `content.js` 里的路径改成文件名，例如：

```js
avatar: 'assets/img/我的照片.jpg',
cover: 'assets/img/项目截图.png',
```

路径区分大小写，建议用英文文件名、不要带空格。

### 换配色

打开 `assets/css/style.css`，最上面三个就是霓虹主色：

```css
--neon-pink: #ff2e97;    /* 主色一：霓虹粉 */
--neon-cyan: #22e0ff;    /* 主色二：霓虹青 */
--neon-violet: #8b5cf6;  /* 主色三：霓虹紫 */
```

换成你喜欢的颜色即可（标题渐变、按钮、光标光晕、网格、按钮发光都会跟着变）。右上角可以在亮色/暗色之间切换，默认跟随系统，切换后会记住。

### 改浏览器标签上的标题

两处保持一致：`content.js` 里的 `meta.title`，以及 `index.html` 里的 `<title>`。

## 上线到公网（让所有人都能访问）

网站是纯静态文件，下面几种方式都免费，选一个就行：

| 方式 | 难度 | 说明 |
| --- | --- | --- |
| **Netlify Drop** | 最简单 | 打开 <https://app.netlify.com/drop>，把整个 `personal-site` 文件夹拖进网页，几秒后拿到一个 `https://xxx.netlify.app` 网址。不注册也能用，注册后可以改名、绑自己的域名 |
| **Cloudflare Pages** | 简单 | 同样支持拖拽上传，国内访问相对稳定 |
| **Vercel** | 简单 | 拖拽或连接 Git 仓库都行 |
| **GitHub Pages** | 稍复杂 | 新建仓库 → 上传这些文件 → Settings → Pages → 分支选 `main`、目录选 `/root` → 得到 `https://用户名.github.io/仓库名/` |
| **国内托管** | 需要备案 | 腾讯云 / 阿里云对象存储的"静态网站托管"，绑自己的域名通常需要备案 |

要点：上传时保持目录结构不变（`index.html` 和 `assets/` 的相对位置不能变），`serve.ps1` 和 `.bat` 可以不传。

## 常见问题

| 现象 | 处理 |
| --- | --- |
| 页面白屏 / 中文乱码 | `content.js` 必须存成 UTF-8 编码（记事本"另存为"时把编码选 UTF-8） |
| 鼠标特效没出现 | 触屏设备、或系统开了"减少动态效果"时会自动只留网格；另外确认是在页面上移动过鼠标 |
| 图片不显示 | 检查路径和大小写；图片要放在 `assets/img/`，路径写成 `assets/img/xxx.jpg` |
| 导航里少了一项 | 说明那个板块的 `items` 是空的，会自动隐藏，正常行为 |
| 改了内容刷新没变化 | 按 `Ctrl + F5` 强制刷新，清掉浏览器缓存 |
| 手机打不开局域网地址 | 确认手机和电脑在同一个 WiFi；公司/学校网络可能隔离设备，可换手机热点试试 |
| 想让别人长期访问 | 用上面的"上线到公网"，本地服务器只适合临时演示 |

## 已经内置的细节

- 跟随鼠标的霓虹光晕、准星光标、网格探照灯、扫描线（触屏自动降级）
- 首屏名字的"故障 glitch"闪烁、状态灯呼吸、爱好跑马灯
- 亮色 / 暗色主题，默认跟随系统，手动切换后记住
- 手机、平板、电脑自适应（实测 390px ~ 1440px 无横向滚动）
- 顶部滚动进度条、当前板块高亮、回到顶部按钮
- 内容滚动入场动画、卡片悬停出现四个角的装饰线
- 相册点击放大、支持 Esc 关闭
- 无任何外部依赖（不加载 CDN 字体和库），断网也能打开
- 支持键盘操作和屏幕阅读器（跳转链接、焦点样式、语义化标签）
