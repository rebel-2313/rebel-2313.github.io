# 06 · 内容维护手册

> 目标：让你在**不改一行代码逻辑**的前提下，随时更新这个网站。
> 记住一句话：**改文字只动 `assets/js/content.js`，改颜色只动 `assets/css/style.css` 顶部。**

---

## 一、修改前的准备

| 准备项 | 说明 |
| --- | --- |
| 编辑器 | VS Code（推荐，免费）/ Notepad++ / 记事本都可以 |
| 编码 | **必须 UTF-8**。VS Code 右下角确认显示 `UTF-8`；记事本"另存为"时把编码选 UTF-8 |
| 备份 | 每次大改前先 `git add -A` + `git commit`，改坏了能一键回退 |
| 预览 | 改完保存 → 浏览器刷新（样式没变就用 `Ctrl + F5`） |

## 二、最常做的 6 件事

### 1) 改个人信息（学校、年级、求职意向）

打开 `assets/js/content.js`，找到 `about.facts`：

```js
facts: [
  { label: '学校专业', value: SCHOOL + ' · ' + MAJOR },   // 自动引用顶部常量，一般不用改
  { label: '求职意向', value: '计算机相关 · 前端开发 / 新媒体技术 · 实习岗' },
  // ...
]
```

只改 `value` 后面单引号里的内容，`label` 不用动。

> **学校名 / 学院名 / 专业名不要在这里改**，去文件顶部的 `SCHOOL` / `COLLEGE` / `MAJOR`
> 三个常量改一次，全站自动同步（这是 v3 单一数据源的改造）。

### 2) 新增一个项目（最重要，面试就看这块）

在 `projects.items` 里复制一项，改内容：

```js
{
  title: '3 分钟剧情短片《xxx》',
  role: '独立完成（课程作业）',        // 我的角色：独立完成 / 负责编剧 / 负责剪辑
  period: '2026.12',
  stack: ['拍摄', 'Premiere 剪辑'],    // 标签 2–4 个即可
  desc: '一部 3 分 20 秒的剧情短片，讲一个宿舍里的小误会，课程展映作品。',
  highlights: [
    '独立完成编剧、分镜、拍摄与剪辑，用到 12 个镜头、4 个场景',
    '现场收音噪声大，改用指向麦 + Premiere 降噪，人声清晰度明显提升',
    '片长 3 分 20 秒，被选为课程展映作品'
  ],
  link: 'https://www.bilibili.com/video/xxx',   // 有片源链接就填，没有留 ''
  linkText: '查看作品'
}
```

写法建议（这是 HR 真正在意的）：

- **每条 highlights 说清"做了什么 + 怎么做的 + 结果如何"**，不要只写"负责开发"；
- 有数字就写数字（记录条数、耗时、评分、排名）；
- "遇到问题并解决"的过程，比罗列功能更有说服力；
- **不要编造**，写不出来的先留着 `【待填】`。

### 3) 更新课程

`courses.groups` 里每个分组是一张卡片，`items` 里每条课程：

```js
{ name: '非线性编辑', meta: '2027 春 · 进行中', note: 'Premiere 素材管理、粗剪精剪、字幕与基础调色。' }
```

学期结束后：把 `meta` 里的"进行中"改成"已修完"；`note` 写一句"我学会了什么"，别空着。

> 本项目按本人要求**不展示课程成绩**，`meta` 里只写学期，不要加分数。

### 4) 拿到新证书

`certs.items` 里加一条：

```js
{ name: '普通话水平测试（二级甲等）', org: '国家语言文字工作委员会', date: '2027.03', status: '已获得', note: '二级甲等', link: '证书图片或查询链接' }
```

`status` 建议只用三种值：`已获得` / `备考中` / `计划中`，一眼能分辨真实与计划。

### 5) 换头像 / 相册图片

1. 把图片放进 `assets/img/`（建议 JPG/PNG，宽度 800px 左右，控制在 300KB 内）；
2. 文件名用**英文或数字**，不要有空格和中文，例如 `avatar-2027.jpg`；
3. 改 `content.js` 里的路径：

```js
avatar: 'assets/img/avatar-2027.jpg',
```

相册在 `gallery.items`，每条是 `{ src: '图片路径', caption: '一句说明' }`。

### 6) 关掉不想展示的板块

- 关掉某个板块：把它下面的 `items`（或 `groups`）改成空数组 `[]`；
- 或者整段删掉（从 `它: {` 到对应的 `},`），页面和导航会一起少一项；
- 例如不想放相册：把 `gallery.items` 改成 `[]`。

## 三、改配色 / 换风格

打开 `assets/css/style.css`，最上面的变量区：

```css
:root {
  --accent: #2563eb;               /* 主色：按钮、链接、关键数字 */
  --accent-soft: rgba(37, 99, 235, .10);
  --accent-line: rgba(37, 99, 235, .32);
}
```

选一个喜欢的颜色（如墨绿 `#0f766e`、酒红 `#9f1239`、靛紫 `#6d28d9`），把三个值一起换（`rgba()` 里的 RGB 数字同步替换）。
注意暗色主题在 `html[data-theme="dark"]` 里另有一份 `--accent`，两处都改才一致。

| 想改什么 | 改哪里 |
| --- | --- |
| 页面最大宽度 | `--max-width`（默认 1080px） |
| 圆角大小 | `--radius`（默认 14px） |
| 正文字号 | `body { font-size: 16px; }` |
| 板块上下间距 | `.section { padding: 68px 0; }` |
| 鼠标微光强度 | `--glow-opacity`（设 0 即完全关掉） |
| 完全不要鼠标微光 | 删掉 `index.html` 里的 `<div class="fx" id="fx">…</div>` |

## 四、语法注意事项（90% 的"页面白了"都是这几条）

1. **引号**必须用英文单引号 `'`，不能用中文引号 `‘’`；
2. 每一项之间用英文逗号 `,`，最后一项后面可以不加；
3. 字符串里想写英文单引号，要用 `\'` 或者外层改双引号；
4. 大括号 `{}`、中括号 `[]` 必须成对；
5. 文件必须存成 UTF-8。

改完页面白屏 → 按 `F12` 打开控制台，第一条红色报错通常会写"第几行 Unexpected token"，回到那一行检查逗号/引号。

## 五、本地预览方式

| 方式 | 操作 | 适合 |
| --- | --- | --- |
| 直接打开 | 双击 `index.html` | 日常改内容 |
| 本地服务器 | 双击 `启动本地预览.bat`（默认 `http://localhost:5180/`，端口被占会自动换下一个并打印出来） | 想用手机看效果 |
| Python | 在目录里执行 `python -m http.server 8080` | 装了 Python 的话 |
| VS Code | 装 Live Server 插件 → 右键 `index.html` → Open with Live Server | 保存自动刷新 |

> 直接用 `file://` 打开时，个别浏览器会限制 `localStorage`（主题记忆失效），这不影响内容显示，放到服务器上就正常。

## 六、导出 PDF 简历

1. 浏览器打开网站，按 `Ctrl + P`；
2. 目标打印机选「另存为 PDF」；
3. 勾选「背景图形」可选（不勾更省墨）；
4. 页边距选「默认」，缩放「默认」；
5. 保存为 `杨叶珥-个人简历.pdf`。

样式表里已写好 `@media print`：打印时会自动隐藏顶栏、按钮、特效和跑马灯，卡片去掉阴影、加细边框，避免内容被分页切断。如果发现某段被切断，可在该板块的 CSS 里加 `break-inside: avoid;`。

## 七、常见问题

| 现象 | 原因 | 处理 |
| --- | --- | --- |
| 页面全部空白 | JS 语法错误 | F12 看控制台，按报错行号修 `content.js` |
| 中文乱码 | 文件不是 UTF-8 | 另存为 UTF-8 |
| 图片不显示 | 路径错 / 文件名带中文或空格 / 大小写不符 | 路径写成 `assets/img/xxx.jpg`，文件名用英文 |
| 改了没变化 | 浏览器缓存 | `Ctrl + F5` |
| 导航里少了一项 | 该板块 `items` 为空 | 正常行为，需要就填数据 |
| 手机上某处横向溢出 | 长英文/长链接撑破布局 | 给对应元素加 `word-break: break-word;` |
| 打印出来有空白页 | 某个板块刚好跨页 | 该板块加 `break-inside: avoid;` |
| **本地预览打开的是别人的网站** | 默认端口被别的程序（另一个项目的预览服务）占了，旧版脚本还会"复用"该端口，于是浏览器把请求交给了那个程序 | 用 `启动本地预览.bat` 打印的实际端口访问；脚本已改为独占绑定 + 自动换端口（默认 5180）。若仍想用 8080，先用 `netstat -ano | findstr :8080` 找到占用进程并关掉它 |
