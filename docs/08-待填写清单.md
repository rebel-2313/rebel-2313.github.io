## 九、填完之后的自检

```powershell
# 1. 确认页面里还有没有残留的占位符
Select-String -Path assets\js\content.js, index.html -Pattern '待填'
# 期望：没有输出（或只剩本文档里的说明性文字）

# 2. 确认没有占位的账号名
Select-String -Path assets\js\content.js -Pattern 'yourname'
# 期望：没有输出

# 3. 本地打开看一眼
start index.html

# 4. 提交并部署
git add -A
git commit -m "content: 补齐真实的学校、项目、课程与证书信息"
powershell -ExecutionPolicy Bypass -File deploy\deploy.ps1 -Server 你的公网IP -User root
```

## 十、填写原则（重要）

1. **不确定就不写**，宁可少写也不要写错——面试官会顺着你的文字追问；
2. **计划中的事必须标注**，把"计划考四级"写成"已过四级"是最常见的翻车点；
3. **数字优于形容词**："优化了查询速度" 不如 "把 1000 条记录的查询从 1.2s 优化到 0.08s"；
4. **每一项都问自己一句：这是我能讲 3 分钟的内容吗？** 讲不清的删掉，比留着更安全。
