# 02 · 设计说明

> 编写日期：2026-11-03 · 版本 v2.0（求职导向改版）

## 一、设计目标

1. **可扫读**：HR 打开后 30 秒内能回答"这人是谁、学什么、会什么、做过什么、怎么联系"。
2. **可维护**：改文字只动一个文件，改配色只动几行变量，不做重复劳动。
3. **可信任**：不吹牛、不乱写，没做的用"计划中"标注，做过的事写清自己的角色与具体动作。
4. **可分发**：手机能看、打印能当简历、部署后任何静态服务器都能跑。

## 二、信息架构（HR 阅读顺序）

```
首屏 hero            姓名 / 身份 / 定位 / 三个按钮 / 4 个关键数字 / 技能跑马灯
  ↓
关于我 about          3 段自我介绍 + 5 条求职信息（学校专业、年级、意向岗位、城市、在学）+ 关键词
  ↓
教育背景 education    学校 + 专业 + 时间 + 主修方向 + 亮点 + 成绩排名
  ↓
专业技能 skills       4 组：编程语言 / 专业基础 / 工具与平台 / 语言与其他（标注掌握程度）
  ↓
项目经历 projects     每项：名称 + 角色 + 时间 + 技术栈 + 一句话简介 + 3 条关键工作 + 仓库链接
  ↓
主修课程 courses      3 组：专业核心课 / 数学与理论 / 通识与工具（含学期、成绩、一句话收获）
  ↓
证书荣誉 certs        名称 + 颁发机构 + 时间 + 状态（已获得 / 备考中 / 计划中）
  ↓
成长轨迹 timeline     专升本大三到大四：已完成的事实 + 可执行的计划
  ↓
校园生活 gallery      真实照片（可整段删除）
  ↓
最近在学 now          在学的技术 / 在刷的题 / 在读的书 / 在准备的考试
  ↓
联系方式 contact      邮箱按钮 + GitHub / Gitee + 备注
```

设计依据：求职材料的经典顺序是「我是谁 → 我在哪读书 → 我会什么 → 我做过什么 → 我学过什么 → 我怎么被联系」，本项目按此顺序排列，把娱乐性内容压缩到时间线之后，且任何一个板块都可以通过修改 `content.js` 一键关闭。

## 三、技术选型

| 事项 | 选择 | 理由 |
| --- | --- | --- |
| 页面结构 | 手写 HTML5 + 语义化标签 | 课程要求手写；语义化利于无障碍与 SEO |
| 样式 | 原生 CSS + CSS 变量（自定义属性） | 主题切换只需切换 `data-theme`，不引入 Sass 等预处理 |
| 脚本 | 原生 ES5 风格 JS（IIFE 模块） | 不依赖框架，兼容性好，方便逐个函数讲清原理 |
| 数据 | 独立 `content.js` 对象 | 内容与视图分离：改内容不碰逻辑，也不易改出语法错误 |
| 图片 | SVG 占位图 + 真实图片可替换 | 体积小、配色可跟随主题，无版权风险 |
| 图标 | 文字符号（✉ ↗ ↑ ☀ ☾） | 免图标字体与 CDN 请求 |
| 部署 | Nginx 静态站点 | 占用小、配置简单，是"服务器简单部署"最典型的做法 |
| 版本管理 | Git（单分支 main + 语义化提交信息） | 个人项目无需复杂分支，但必须保留清晰的演进过程 |

### 为什么用"数据 + 渲染"两层结构

```
content.js  ──(被读取)──▶  main.js  ──(生成 DOM)──▶  浏览器页面
  纯数据                   渲染逻辑                    最终效果
```

- 好处 1：改文字时只在数据里改，不用担心把 HTML 标签写坏；
- 好处 2：新增一个板块只需在 `content.js` 加数据 + 在 `main.js` 加一个 `renderXxx()` 函数；
- 代价：正文由 JS 生成，源码里看不到文字。为弥补这一点，同时提供 `resume.md`（纯文本简历）并在 `index.html` 的 `<noscript>` 中给出提示与链接。

## 四、视觉设计

### 4.1 配色

| 角色 | 亮色主题 | 暗色主题 | 用途 |
| --- | --- | --- | --- |
| 背景 | `#f7f8fa` | `#0b1220` | 页面底色 |
| 卡片 | `#ffffff` | `#111a2b` | 卡片、信息框 |
| 次要底色 | `#f1f3f7` | `#16223a` | 标签、分隔条 |
| 正文 | `#14171d` | `#e9eef8` | 主要文字 |
| 次要文字 | `#5b6472` | `#9aa7bd` | 说明、时间、备注 |
| 边框 | `#e4e7ee` | `#1f2b41` | 卡片描边 |
| 强调色 | `#2563eb` | `#6ea8fe` | 链接、关键数字、状态 |

改版前后对比：旧版是粉/青/紫三色霓虹 + 深底发光，视觉冲击强但阅读疲劳；新版只保留**一个**强调色，其余全部用中性色，强调色只出现在"需要被注意的地方"（小标题、链接、关键数字、状态标签）。

### 4.2 字体与排版

- 字体栈优先系统中文字体（苹方 / 微软雅黑 / 思源黑体），**不加载网络字体**；
- 正文 16px / 行高 1.75，中文长文更易读；手机端 15.5px；
- 标题用 `clamp()` 做流式缩放，避免小屏标题过大；
- 数字、时间、代码相关文字使用等宽字体 `--font-mono`，与正文形成对比，便于扫读；
- 板块之间用 1px 分隔线 + 68px 上下留白，形成呼吸感而不是靠阴影堆叠。

### 4.3 交互与动效（刻意做减法）

| 交互 | 旧版 | 新版 |
| --- | --- | --- |
| 鼠标跟随光效 | 光晕 + 准星圆环 + 粉点 + 网格探照灯 + 扫描线 | 仅保留一团极淡的强调色微光，1.6 秒无操作自动淡出 |
| 名字动效 | 故障闪烁 glitch | 取消，改为纯色标题 |
| 卡片装饰 | 悬停出现四角霓虹边线 | 取消，改为轻微上浮 + 边框变色 |
| 入场动画 | 逐板块位移淡入 | 保留，但幅度从 24px 减到 14px |
| 滚动进度条 | 有 | 保留（细节感，且不干扰） |

理由：求职页面的动效应服务于"引导注意力"，不是展示技术。所有动效都可以在系统设置了"减少动态效果"时自动关闭。

### 4.4 响应式断点

| 断点 | 布局变化 |
| --- | --- |
| ≥ 901px | 首屏两栏（文字 + 头像），关于我两栏，项目/课程多列网格 |
| 621–900px | 首屏单栏、头像置顶缩小，导航收进右上角菜单按钮 |
| ≤ 620px | 字号略降、卡片内边距收紧、证书卡片单列、时间线缩进减小 |

## 五、页面结构与代码组织

```
index.html
├─ <head>  静态元信息：title / description / og / JSON-LD / 主题预热脚本
├─ 装饰层   <div class="fx">  一团跟随鼠标的微光
├─ 顶栏     brand + 导航（由 JS 按实际渲染的板块生成）+ 主题按钮 + 菜单按钮 + 进度条
├─ <main>  由 main.js 依次 append 各板块
├─ 页脚    版权 + 一句技术说明 + 更新时间
└─ 灯箱    相册点击放大的遮罩层
```

`main.js` 的函数职责一览：

| 函数 | 作用 |
| --- | --- |
| `renderHero` / `renderAbout` | 首屏与关于我 |
| `renderEducation` | 教育背景（v2 新增） |
| `renderSkills` / `renderProjects` | 技能、项目经历 |
| `renderCourses` | 主修课程（v2 新增） |
| `renderCerts` | 证书荣誉（v2 新增） |
| `renderTimeline` / `renderGallery` / `renderNow` | 成长轨迹、相册、最近在学 |
| `renderContact` / `renderFooter` | 联系方式、页脚 |
| `sectionShell` | 统一板块外壳（小标签 + 标题 + 副标题 + 自动登记导航） |
| `setupTheme` / `setupMenu` / `setupScroll` | 主题、移动端菜单、滚动进度与回顶 |
| `setupReveal` / `setupActiveNav` | 入场动画、导航高亮 |
| `setupLightbox` / `setupCursorFX` | 图片放大、鼠标微光 |

## 六、无障碍设计

- 顶部有"跳到主要内容"链接，键盘 Tab 第一个就能用；
- 所有交互元素都有可见焦点样式（`:focus-visible`）；
- 装饰性元素统一 `aria-hidden="true"`，不影响读屏；
- 相册按钮带 `aria-label="放大图片：xxx"`，灯箱支持 Esc 关闭并把焦点还给触发按钮；
- 导航展开按钮维护 `aria-expanded` 状态；
- 尊重 `prefers-reduced-motion`：关闭入场动画、跑马灯、鼠标光效。

## 七、SEO 与分享

- `<title>` / `description` / `author` / `keywords` 静态写在 `index.html`；
- Open Graph 标签保证微信、QQ、微博分享时有标题和描述；
- JSON-LD `Person` 结构化数据声明姓名、学校、技能、邮箱，便于搜索引擎正确理解"这是一个人的主页"。

## 八、后续可扩展方向

1. 拆分多页（`projects.html` 详情页），项目多起来后单页会过长；
2. 简历 PDF 自动生成：用浏览器 `打印 → 另存为 PDF`（本项目已做打印样式），或后续接入 Node 端模板；
3. 接入访问统计（如自建 Umami），了解哪些板块被看得最多；
4. 增加英文版页面，为以后投递外企做准备。
