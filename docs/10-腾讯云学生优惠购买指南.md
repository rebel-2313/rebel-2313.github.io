# 10 · 腾讯云学生优惠买服务器指南（力度最高买法）

> 目的：用**学生身份能拿到的最低价**，买一台够放静态个人主页的云服务器。
> 查询时间：2026-11-17。价格与活动会变，最终以官方活动页登录后的实时显示为准。
> 官方入口：**https://cloud.tencent.com/act/campus** （腾讯云「云 + 校园」）

## 一、结论先说（最省钱的买法）

放一个纯静态主页，**2 核 2G / 4M 带宽** 完全够用（整站不到 300KB）。所以力度最高、又不过度花钱的选择是：

> **完成学生认证 → 校园计划买「轻量应用服务器 2 核 2G / 4M / 300G 流量 / 40G SSD」→ 时长选 1 年（折扣最低，约 1.3 折，几十元/年）→ 镜像选 Ubuntu 22.04 LTS → 地域选离自己近的（成都无节点则选重庆/上海/广州）**

为什么这么选：

| 考量 | 说明 |
| --- | --- |
| 为什么不是 2 核 4G | 静态站用不到 4G 内存，多花钱；除非以后要跑数据库/多站点 |
| 为什么选 1 年 | 学生价时长越长折扣越低（3 月 1.8 折 / 6 月 1.6 折 / 1 年 1.3 折），1 年性价比最高 |
| 为什么轻量而不是 CVM | 轻量应用服务器自带防火墙、监控，控制台更简单，学生价也更便宜；CVM 2 核 4G 要 789 元/年，没必要 |
| 为什么 Ubuntu 22.04 | 本项目的部署脚本、`docs/05` 的命令都基于它，照抄即可，不用改 |
| 限购 | 校园云服务器**三选一、限购 1 台**，选了就不能再换，想清楚再下单 |

三款学生服务器对比（校园计划，需学生认证）：

| 产品 | 规格 | 折扣/价格（参考） | 适合 |
| --- | --- | --- | --- |
| **轻量 2 核 2G** | 4M / 300G / 40G SSD | 1 年约 1.3 折，约 26–27 元/年 | ✅ 静态主页首选 |
| 轻量 2 核 4G | 5M / 500G / 60G SSD | 1 年约 2 折，约 168 元/年 | 多站点 / 带数据库 |
| CVM 2 核 4G | 3M / 100G SSD | 约 789 元/年 | 科研 / 要更高可控性 |

> 数据库（TDSQL-C MySQL 1 核 1G）学生价 0.3 折、约 4 元/月，本站用不上，以后要加后端再买。

## 二、购买步骤（照着点）

### 第 1 步：注册并实名认证
1. 打开 https://cloud.tencent.com/act/campus ，用微信或手机号注册；
2. 完成**实名认证**（个人实名，需身份证）。

### 第 2 步：完成学生认证（关键，决定能不能买学生价）
1. 在活动页找「**学生认证**」入口，点击进入；
2. 按提示用学信网 / 学生证信息认证（本人 2026 级专升本在读，学籍在有效期内即可）；
3. 认证通过后，活动页的价格和「立即购买」按钮才会解锁。
   - 学生认证通常一年有效，毕业前用完。

### 第 3 步：下单
1. 回到活动页「校园云服务器」区，在「轻量应用服务器 2 核 2G」卡片下：
   - 时长选 **1 年**；
   - 地域选 **上海 / 广州 / 北京**（离你近、延迟低）；
   - 镜像选 **Ubuntu 22.04 LTS**；
2. 点「立即购买」，确认订单（确认价格是学生价，不是原价）；
3. 支付。

### 第 4 步：拿到服务器信息
付款后，在「控制台 → 轻量应用服务器」能看到实例：
- **公网 IP**：记下来（部署要用）；
- **登录方式**：创建时设置 root 密码（够长，16 位以上），或用 SSH 密钥。

### 第 5 步：放行端口
控制台 → 该实例 →「防火墙」→ 添加规则，放行：
- `22/TCP`（SSH 登录）
- `80/TCP`（HTTP 访问）

## 四、省钱补充（可选）

- **别买域名也能满足"公网可访问"**：直接用 `http://公网IP/` 访问即可，域名 + 备案是另一回事，可以后再加。
- **校园优惠与个人新客优惠不冲突**：校园价买 1 台后，还能用个人新客身份另抢 38 元/年的秒杀款（配置更高）。但**本站一台 2 核 2G 绰绰有余，没必要多买**。
- **续费**：学生价限购 1 台；到期续费价格看当年政策，到期前留意活动页「续费」说明，别默认按原价续。
- **证书**：HTTPS 要域名，且国内服务器域名要 ICP 备案。学习/作业阶段先用 HTTP + IP，不必急着上 HTTPS。
